Quantum Amplitude Estimation Challenge Leaderboard

Standardized, phase-estimation-free benchmark comparing non-adaptive (1 parallel round), semi-adaptive, and sequentially adaptive Quantum Amplitude Estimation algorithms for estimating a = sin(θ) ∈ (0.1, 0.9) from Z-basis Grover measurements with probability p(n,θ) = cos²((2n+1)θ). All community submissions are certified in a sandboxed CI pipeline using a blind cryptographic GitHub Actions secret seed (LEADERBOARD_SECRET_SEED) so algorithms cannot overfit to a fixed test set.

Literature Baselines (2020–2026). Classical QPE-free baselines span non-adaptive schedules (MLAE-Linear and MLAE-Pow2 by Suzuki et al. 2020; csAE by Labib et al. 2024; mlqae-plain and mlqae-flagship by Labib 2026) and sequential adaptive interval/Bayesian protocols (FAE Nakaji 2020; IQAE-Chernoff & IQAE-CP Grinko et al. 2021; chebAE Rall & Fuller 2023; BIQAE 2024; BAE-Adaptive Ramôa & Santos 2024).

Dense-Ladder Maximum Likelihood vs. Powers of Two. Power-of-two schedules (r = 2) space rungs so far apart that each basin-disambiguation step rests on a single rung, requiring either many shots per rung (MLAE-Pow2, C95 ≈ 7.88) or adaptive confidence intervals (IQAE, chebAE). Using a dense geometric ratio r = 1.45 plus one degeneracy-breaking rung at round(nmax/1.3) reaches C95 = 2.82–2.88 and C95seq = 0.21 in a single parallel round.

The Open Challenge Frontier. On the canonical schedule, the exact scale-mixture Cramér–Rao bound sits at C95CRLB ≈ 1.67 and the exact Monte-Carlo Ziv–Zakai lower bound at C95ZZB ≈ 1.94. Can a 2-round semi-adaptive or fixed-budget adaptive schedule close the gap between 2.82 and the information-theoretic floor?

Blind Cryptographic CI Certification (LEADERBOARD_SECRET_SEED). To prevent hyperparameter overfitting or seed-table memorization, community Pull Requests undergo two-tier verification: Tier 1 runs a sandbox smoke check on SEARCH_SEED = 100,000, while Tier 2 certifies official rankings on HOLDOUT_SEED = 900,000 plus an HMAC-SHA256 seed derived from LEADERBOARD_SECRET_SEED inside a network-isolated unshare -r -n container.

Submit an Algorithm to the QAE Challenge Leaderboard

Submissions are evaluated via GitHub Pull Request in a network-isolated sandbox (unshare -r -n) against QuantumAEOracle. Local development and tuning are permitted on SEARCH_SEED = 100,000; official leaderboard rankings are certified on HOLDOUT_SEED = 900,000 plus a blind cryptographic GitHub Actions secret seed (LEADERBOARD_SECRET_SEED) across nmax ∈ {60, 125, 260, 540}.

3. Implement submission.py (Sandbox Oracle API)

import numpy as np
from leaderboard.schema_and_api import (
    AdaptiveAESubmission, QuantumAEOracle, ml_estimate_batch
)
from mlqae.core import flagship_schedule

class MySubmission(AdaptiveAESubmission):
    name = "my_custom_qae"
    track = "adaptive-fixed-budget"

    def run_trial(self, oracle: QuantumAEOracle, target_scale_or_budget: int, rng: np.random.Generator) -> float:
        # Call oracle.measure_batch(depths, shots) for parallel rounds
        # or oracle.measure(depth, shots=1) for sequential adaptive steps.
        depths, shots = flagship_schedule(int(target_scale_or_budget))
        counts = oracle.measure_batch(depths, shots)
        return float(ml_estimate_batch(depths, shots, counts))

4. Verify Locally & Open a Pull Request

OPENBLAS_NUM_THREADS=2 .venv/bin/python leaderboard/verifier_and_runner.py --mode=verify --submission=leaderboard/submissions/my_custom_qae --ntrials=2000 --seed=100000
